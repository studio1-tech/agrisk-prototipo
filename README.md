# AGrisk · protótipo navegável

Inteligência meteorológica e perícia em campo, da contratação à liquidação, usando dados da API Smart Grower.

Abra `index.html` (vai para o login). Telas: Login → Sala de controle → Carteira → Contratação → Monitoramento → Aviso de sinistro → Perícia (+ app do perito) → Regulação → Liquidação.

Dados e números são ilustrativos. `support.js` é um runtime leve que interpreta os arquivos `.dc.html` no navegador.
